Read and understand

Mechatronics combines mechanical structures, electronics and software to create systems that can sense, decide and act. Automatic doors, robotic arms, drones and smart vehicles are all examples because physical components are controlled by electronic circuits and algorithms.

Some systems are controlled directly by a person, while others operate autonomously using sensors and programmed decisions. Many real products combine both approaches by allowing manual control, automatic operation and an emergency override.

In this unit, a micro:bit V2 will control a two-wheel sumo robot. The robot must detect the ring boundary, locate an opponent and control its motors so it remains inside the arena while attempting to push another robot out.

Read and understand

A microcontroller is a small computer designed to control a device. The micro:bit V2 contains a processor, memory, programmable pins, buttons, sensors, an LED display and communication features.

In a robot, the micro:bit receives input data from sensors, processes that data using an algorithm and sends output signals to the Motor:bit board. The Motor:bit then supplies the current required by the two DC motors.

The micro:bit cannot safely power the robot motors directly from its pins. The motor driver board forms an interface between the low-power controller and the higher-current motors.

Read and understand

Iteration repeats instructions. A robot control program normally uses a continuous loop to poll sensors, make decisions and update motor outputs.

Delays can make movement predictable, but long delays reduce responsiveness because the robot cannot check sensors while it is sleeping. Short loops usually produce safer autonomous behaviour.

Count-controlled loops are useful for calibration tests, while condition-controlled loops are useful for waiting until a sensor changes.

Read and understand

The Motor:bit board accepts low-power commands from the micro:bit and switches the higher current required by two DC motors. This protects the controller and allows direction and speed control.

Motor speed is controlled by rapidly switching power on and off using pulse-width modulation. Direction changes when the driver reverses the voltage applied to a motor.

Real motors rarely behave identically. Friction, wheel size, gearbox variation and battery voltage may require different left and right speed settings.

Read and understand

An ultrasonic sensor estimates distance by sending a pulse of high-frequency sound and measuring how long the echo takes to return.

Readings can be affected by angled surfaces, soft materials, nearby robots and electrical noise. Programs should reject impossible values and avoid relying on one reading.

The sensor can detect an object in front of the robot but cannot identify what the object is. Its data must be combined with tracking-sensor information.

from microbit import *
import machine, time
TRIG = pin15
ECHO = pin16

def distance_cm():
    TRIG.write_digital(0)
    time.sleep_us(2)
    TRIG.write_digital(1)
    time.sleep_us(10)
    TRIG.write_digital(0)

Read and understand

A simple opponent detector compares measured distance with a selected threshold. When an object is close enough, the robot drives forward to attack.

When no opponent is detected, the robot needs a search pattern. It may spin, sweep left and right or move in short arcs.

A threshold that is too large causes false attacks, while one that is too small delays the response. Testing should use the actual ring and opponent shapes.
