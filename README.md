# Year 10 Computing Technology – Mechatronics

Interactive 12-week unit based on a micro:bit V2 sumo robot project.

## Publish using GitHub Pages

1. Create a GitHub repository or open your existing repository.
2. Upload all files from this package to the root of the repository.
3. Ensure the main webpage is named `index.html`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.

Your site will normally be published at:

`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Included files

- `index.html` – complete interactive teaching unit
- `Year10_Mechatronics_Assessment_Task.pdf` – assessment task
- `.nojekyll` – tells GitHub Pages to serve the files directly

## Notes

- The school logo is embedded directly into `index.html`.
- Student responses and progress are saved in the current browser using local storage.
- Saved work will not automatically transfer to another device or browser.
- The MakeCode embeds and external tutorial links require internet access.
- Hardware code may require the correct Motor:bit library, ultrasonic model and pin assignments used by the class.
